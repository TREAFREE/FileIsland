01 · Mixed media

One folder, separate controls.一个文件夹，分别设置

Drop images, video, and audio together. File Island groups each media type and preserves its own conversion choices.

02 · Images

Choose format, size, and quality.选择格式、尺寸与质量

Convert a single image or a batch to JPEG or PNG with explicit quality, dimensions, target size, and metadata controls.

03 · Video

Convert or split for sharing.转换，或快速切分后分享

Use high-compatibility H.264 MP4 output, or split eligible H.264 MP4/MOV files at safe keyframes without re-encoding.

04 · Audio

Pick a useful audio output.选择合适的音频格式

Convert supported audio inputs to M4A, WAV, FLAC, or AIFF without installing a separate media runtime.

05 · Settings

Set it once, then keep moving.设置一次，之后直接使用

Choose a persistent output folder, language, appearance, login behavior, and optional single-file Clipboard copy.
