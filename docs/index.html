Why File Island · 为什么选择它

A converter that stays out of your way.

File Island turns the top of your Mac into a practical drop target. It handles everyday media without sending private files to a website or asking you to learn command-line flags.

⌄

Drop it into the notch.

The compact island expands only when you bring files to it, then shrinks into a progress view while the job runs.拖入刘海，展开设置；开始后自动回缩并展示进度。

∞

Mix files in one folder.

Images, video, and audio are grouped by type, so one folder can keep separate settings for every media family.混合文件夹会按图片、视频和音频分别设置，一次批量处理。

⌁

Keep the work local.

No account and no upload. The app ships with its conversion runtime and saves results to the output folder you choose.无需账号，无需上传，也不用额外安装转换依赖。
