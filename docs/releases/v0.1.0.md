# File Island 0.1.0 — unsigned early access

File Island is a local-first macOS image and video converter that lives around the top of the display. Drag files or an ordinary folder from Finder into the Island, choose format and size settings, then convert into one previously authorized output folder.

> **Important:** This build is ad-hoc signed. It is not signed with Apple Developer ID and has not been notarized by Apple. macOS will normally block the first launch. Download only from this official GitHub Release, verify the attached SHA-256 value, and follow [Apple's Open Anyway instructions](https://support.apple.com/guide/mac-help/mh40616/mac). Do not disable Gatekeeper.

## Requirements

- macOS 15 or newer;
- Apple silicon or Intel Mac;
- no Homebrew, separate FFmpeg, Python, Node.js, account, or network service required.

## Included in 0.1.0

- HEIC, HEIF, JPEG, PNG, WebP, and TIFF input with verified JPEG/PNG output;
- image dimension, quality, metadata-removal, and per-file target-size controls;
- MOV, MP4, and M4V to high-compatibility H.264/AAC MP4 using AVFoundation;
- MKV and WebM to H.264/AAC MP4 using the bundled FFmpeg 8.1.2 fallback;
- Source, 1080p, and 720p video resolution ceilings without upscaling;
- optional native-video target sizes;
- recursive ordinary-folder discovery and heterogeneous image/video batches;
- collision-safe output naming, cancellation, whole-batch rollback, and saved output-folder authorization;
- top Island, menu-bar controls, four-pane Settings, real progress, and Reduce Motion support;
- structured `fileisland` CLI source and scheme for automation users.

## Known limitations

- MP3 and other audio files can be identified but cannot yet be converted;
- WebP is input-only; JPEG and PNG are the verified image outputs;
- MKV/WebM fallback does not offer an exact output-size target;
- animated images, RAW, PDF, AI/natural-language commands, editing, and remote services are not included;
- managed Macs may prevent the Gatekeeper Open Anyway override;
- this early-access DMG has no automatic updater.

## Install

1. Download `FileIsland-0.1.0-unsigned.dmg` and its `.sha256` file.
2. In Terminal, run `shasum -a 256 ~/Downloads/FileIsland-0.1.0-unsigned.dmg` and compare it with the attached checksum.
3. Open the DMG and drag **File Island** into **Applications**.
4. Try to open File Island once. When macOS blocks it, open **System Settings → Privacy & Security**, scroll to Security, and choose **Open Anyway** for File Island.
5. Confirm only if the file came from this official Release and its checksum matched.
6. Choose an output folder the first time you start a conversion.

File Island processes conversions locally.
