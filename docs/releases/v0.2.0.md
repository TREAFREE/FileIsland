# File Island 0.2.0 — unsigned early access

File Island 0.2 turns the first public image/video utility into a bilingual local media converter while keeping the same fail-closed, no-upload design.

## Highlights

- System, English, and Simplified Chinese UI with immediate switching.
- Audio conversion from MP3, WAV, AIFF, M4A/AAC, FLAC, OGG/Opus, and AC3 to M4A, WAV, FLAC, or AIFF.
- GIF, BMP, and AVIF image input plus AVI, MPEG, TS, FLV, 3GP, and WMV video input.
- Shared GUI/CLI capability matrix, folder grouping, rollback, real progress, and validated outputs.
- Larger menu-bar artwork and a conventional DMG with an Applications shortcut.
- Bilingual tutorials, explicit format matrix, and continuous integration.

MP3 output is intentionally not included. WebP remains input-only. See the bundled format matrix and third-party notices for exact boundaries.

## Install

Download `FileIsland-0.2.0-unsigned.dmg` and its checksum, verify with `shasum -a 256`, open the DMG, and drag File Island to Applications. Because this build has no Developer ID signature or notarization, macOS may require **System Settings → Privacy & Security → Open Anyway** after the first launch attempt. Do not disable Gatekeeper.

The app contains universal arm64/x86_64 binaries and the audited FFmpeg runtime; users do not need Homebrew or another dependency.
