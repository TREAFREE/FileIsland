File Island guide · Mac media converter

Convert everyday media without sending it away.

File Island brings images, video, audio, and ordinary folders into one local Mac workflow. It lives near the top of the display, expands when files arrive, and keeps the conversion on your computer.在 Mac 本地处理图片、视频、音频和混合文件夹，无需把私人媒体上传到在线网站。

One coordinated job

Different media. Different settings.

A mixed folder does not force every file through the same format. File Island groups eligible images, video, and audio, then lets each group keep its own output choices.

What it solves

A focused alternative to uploads and command lines.

Online converters can be convenient, but they normally need the source media to leave your Mac. FFmpeg is powerful, but a one-off conversion should not require memorizing container, codec, quality, and output-path flags. File Island packages a verified subset into a native interface and includes the required runtime in the app.

适合什么人？ 经常从 iPhone、相机、录屏或聊天软件中收到不同媒体文件，希望在 Mac 上批量整理、压缩或转换，但不想上传隐私文件，也不想维护命令行环境的用户。

Basic workflow

From Finder to finished files.

Drop files or a folder

Drag one file, multiple selections, or an ordinary folder from Finder to the top of the screen.

Choose per-media results

Image, video, and audio groups show only settings that apply to that media family.

Authorize one output folder

On the first job, choose a folder once. File Island stores a scoped authorization and reuses it later.

Use the result shelf

Reveal outputs in Finder, copy a single result, or drag completed files into another compatible app.

Verified scope

What version 0.3.3 handles.

  • Images: common HEIC, HEIF, JPEG, PNG, WebP, and TIFF inputs, with verified JPEG or PNG output.
  • Video: compatible inputs can be normalized to H.264/AAC MP4 with Source, 1080p, 720p, and target-size controls.
  • Audio: supported inputs can become M4A, WAV, FLAC, or AIFF.
  • Folders: mixed media can be discovered recursively while preserving safe relative structure.
  • Automation: the app and structured CLI share the same conversion core and fail-closed rules.

File extensions alone do not prove that the internal codec is supported. File Island inspects the file and stops safely when it cannot verify the requested path.

Honest current limits

MP3 and WebP are input-only. RAW and animated-image output, general editing and merging, and precise re-encoded video splitting are not in the current release. Fast video splitting is limited to eligible H.264 MP4/MOV sources with AAC audio or no audio.
