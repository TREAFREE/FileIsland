Compatible output

MP4 with verified video and audio settings.

File Island routes eligible sources through a tested H.264/AAC MP4 plan instead of assuming that a filename extension proves compatibility.

Container versus codec

Changing “MOV” to “MP4” is not enough.

MOV and MP4 are containers. The encoded video and audio streams inside determine whether another device or service can actually play the file. File Island inspects the media and, when eligible, creates an MP4 using H.264 video and AAC audio for broad everyday compatibility.

Renaming .mov to .mp4 does not convert the streams and can produce a misleading or unusable file.

Steps

Convert MOV to MP4 locally.

Drop the MOV source

Drag one video, several videos, or a folder from Finder to File Island.

Choose MP4

The video group shows compatible output controls. Select the MP4 conversion workflow.

Choose dimensions or a target size

Source keeps the source dimensions; 1080p and 720p limit output dimensions. An eligible target-size choice can reduce dimensions internally to meet a stricter limit.

Start and review

The source is never overwritten. File Island validates and publishes a collision-safe output to the authorized folder.

Choosing a size

Source, 1080p, and 720p describe dimensions.

These choices are about video dimensions rather than a fixed file size. File size also depends on duration, motion, audio, and bitrate. Use a target-size option when the destination has a strict upload limit; use Source when preserving dimensions matters more than reducing bytes.

Source、1080p、720p 指的是视频尺寸。 它们并不承诺固定的文件体积。视频时长、画面复杂度、帧率和音频都会影响最终大小。

Verified boundary

File Island 0.3.3 produces verified H.264/AAC MP4 output for eligible sources. A matching .mov extension alone is not a guarantee: unsupported codecs, damaged timing, or files that cannot be safely inspected are rejected without replacing the source.
