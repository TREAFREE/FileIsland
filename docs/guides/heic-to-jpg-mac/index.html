Why JPEG

Compatibility for everyday sharing.

HEIC often stores photos efficiently, but some websites, document systems, and older apps still expect JPEG. Converting a copy to JPEG can make the image easier to attach or upload while leaving the HEIC source untouched.

JPEG does not preserve transparency. If a source image needs transparent pixels, choose PNG instead.

Steps

Convert HEIC to JPEG on Mac.

Drop the photo

Drag one HEIC/HEIF image, several photos, or a folder from Finder to File Island.

Select JPEG

In the image group, choose JPEG. Keep the default quality or adjust it for the destination.

Choose optional constraints

Set maximum dimensions or a target size. Decide whether the output should keep supported metadata.

Start and use the result

The source remains unchanged. Reveal the JPEG in Finder, copy a single output, or drag it from the result shelf.

Quality and privacy

What the controls mean.

  • Quality changes JPEG compression. Higher quality normally means a larger output.
  • Maximum dimension limits the longer edge while preserving the image aspect ratio.
  • Target size asks File Island to search for a result under the selected byte limit when the input is eligible.
  • Remove metadata writes a new output without supported metadata; it never deletes the source photo.

提示：“移除元数据”删除的是新输出文件中的位置、设备等附加信息，不会删除源文件。对需要保留拍摄信息的归档照片，请关闭这一选项。

Verified boundary

Version 0.3.3 supports verified JPEG and PNG image output. WebP is currently input-only, and RAW or animated-image output is not supported. Damaged or unsupported inputs fail safely.
