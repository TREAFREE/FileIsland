# Privacy

Last updated: August 10, 2026

File Island is a local-first macOS file conversion utility.

## Data processing

- Selected files and folders are inspected and converted on the user's Mac.
- File Island does not upload media, filenames, conversion settings, or output files to a File Island server.
- File Island has no account system, advertising SDK, analytics SDK, crash-reporting SDK, or telemetry service.
- Conversion does not require an Internet connection.

## Data stored on the Mac

File Island stores user preferences and an app-scoped security bookmark for the output folder selected by the user. These values remain in the user's macOS account and can be removed by deleting the app's container/preferences.

Source files are never intentionally overwritten. Temporary conversion data is removed after completion, cancellation, or a handled failure. Output files are written only to the folder authorized by the user or explicitly supplied to the command-line interface.

## External links

Choosing **Report Issue** opens the File Island GitHub Issues page in the default browser. GitHub then applies its own privacy terms. Do not attach private or sensitive media to a public issue.

## Future changes

Any future network service, update checker, analytics feature, or crash-reporting integration must be disclosed here before release. The policy's “Last updated” date will change when its substance changes.

Questions and public bug reports may be submitted through [GitHub Issues](https://github.com/TREAFREE/FileIsland/issues). Security vulnerabilities must follow [SECURITY.md](SECURITY.md).
